# GHIA THERMA

Reversible thermoacoustic thermal platform — conceptual/pre-prototype engineering record.

## Architecture lock
- Fixed thermoacoustic hardware
- Oscillating working gas
- No piston, displacer, crankshaft, connecting rod, flywheel, reciprocating mechanical compressor, or mechanical bearings in the core architecture
- Separate secondary thermal loops
- Instrumentation, adaptive control, and independent safety layers
