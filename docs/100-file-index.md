# GHIA THERMA — 100-File Engineering Documentation Index

This repository is the canonical text-first documentation baseline for GHIA THERMA. The project is conceptual/pre-prototype; simulation outputs are not hardware measurements. The locked 3.5 architecture is a fixed-hardware thermoacoustic core with oscillating working gas and no piston, displacer, crankshaft, connecting rod, flywheel, or mechanical-bearing core.

## Documentation rule
Each numbered file is intended to hold a substantial engineering chapter (target 300–500 lines) when completed. Source-derived material, first-principles calculations, THERMA screening assumptions, and hardware-only facts must remain distinguishable. No generated image or illustrative number is to be treated as a fabrication specification without independent validation.

## Existing visual assets
The project generated approximately 35 individual visual artifacts during the first illustration pass. They are treated as communication assets, not authoritative geometry. Several late visuals drifted into piston/Stirling-like architecture and are therefore excluded from THERMA 3.5 architecture claims; the final image/diagram index must mark them as invalid, historical, or replaceable rather than silently reusing them.

## Source baseline
The supplied GHIA THERMA technical dossier states that THERMA is conceptual/pre-prototype, that thermoacoustic physics is established, and that exact geometry, materials, pressure integrity, certification and THERMA-specific performance remain to be validated. It also explicitly distinguishes established science, first-principles calculations, THERMA model outputs and hardware-only facts.
